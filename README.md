# AvyOS
A webos with a real bash implementation powering it all.

## Usage
It is deployed on Vercel [here](https://webos-iota-two.vercel.app/)

## Features
- Real Filesystem stored in memory
- Multiple Apps
- Weather App that pulls from Open-meteo api
- Clock App
- Folders on desktop that update from filesystem

## Development
1. run `bun install`
2. To Get a hot reload dev server run `bun run dev`
3. To build run `bun run build`
